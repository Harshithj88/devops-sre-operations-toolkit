# Resume Bullets

## Project: DevOps & SRE Operations Toolkit

### Summary

Production-grade operations toolkit demonstrating core DevOps & SRE job duties across hybrid (on-premises + Azure) environments — infrastructure automation, CI/CD pipeline design, server fleet management, monitoring, incident response, security compliance, and release orchestration.

### Key Accomplishments

- Designed and implemented **multi-stage CI/CD pipelines** (Azure DevOps + GitHub Actions) for .NET, IIS, and Kubernetes deployments with manual approval gates and automated rollback
- Built **PowerShell automation suite** for server fleet management: rolling restarts, app pool recycling, certificate lifecycle management, disk monitoring, and post-deploy health validation
- Authored **Azure Bicep IaC modules** for App Service, Key Vault, Azure SQL, and Log Analytics with environment-parameterized deployments and diagnostic integration
- Created **KQL-based monitoring dashboards** and **Bicep alert rules** for availability, performance, and error-rate tracking with deployment correlation analysis
- Developed **security compliance automation** including TLS auditing, server baseline validation, and zero-downtime Key Vault secret rotation
- Implemented **OIDC-based authentication** for GitHub Actions → Azure deployments, eliminating stored credentials

### Technologies

Azure, Azure DevOps, GitHub Actions, PowerShell 7, Azure Bicep, Kubernetes (AKS), Helm, IIS, .NET, Azure Key Vault, Azure Monitor, Log Analytics, KQL, Docker, Git
